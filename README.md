# Nocturne Rose

Nocturne Rose is a dark gothic Minecraft skin featuring a female character with long silver-white hair, a burgundy rose attached to the hair, an elegant black dress with a fitted corset, silver chains, and a black cloak with burgundy lining. The skin includes detailed front and back views, making it a fully playable and visually striking texture pack for Minecraft.

## Install

1. Download the `gothic_skin.svg` file from the repository.
2. Open Minecraft and navigate to the `resourcepacks` folder in your Minecraft directory.
3. Place the downloaded `gothic_skin.svg` file into the `resourcepacks` folder.
4. Launch Minecraft and select the Nocturne Rose resource pack in the resource pack menu.

## Use

1. Launch Minecraft and select the Nocturne Rose resource pack.
2. Create a new world or load an existing one.
3. Spawn or create a new character to see the Nocturne Rose skin in action.
